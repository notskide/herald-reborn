# Herald Reborn roadmap

This roadmap is provisional and will change as the project is tested.

## Phase 1 — Knowledge foundation

- [x] Create repository overview and initial knowledge entries
- [x] Define entry conventions and a JSON index
- [ ] Add automated checks for index paths, duplicate IDs, and broken related links
- [ ] Choose and add an explicit open-source license
- [ ] Expand the knowledge set with reviewed, sourced entries

## Phase 2 — Search

- [ ] Implement lightweight keyword search
- [ ] Add tag and status filters
- [ ] Measure results against a small query test set
- [ ] Explore semantic or hybrid retrieval only if needed

## Phase 3 — Assistant integration

- [ ] Define a small, documented retrieval interface
- [ ] Prototype an assistant that cites retrieved entries
- [ ] Keep external browsing separate from repository facts
- [ ] Track source freshness and uncertainty

## Phase 4 — Controlled growth

- [ ] Propose candidate updates from approved sources
- [ ] Validate and review changes before merging
- [ ] Keep a transparent change history
- [ ] Evaluate quality, latency, and memory use as the corpus grows

## Guiding principle

Build observable, testable pieces first. A growing repository is useful when updates remain accurate, traceable, and easy to maintain.
